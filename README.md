# Yashwanth Portfolio — TypeScript + Vite

This is the supplied standalone HTML portfolio converted into a **Vite + TypeScript** project. The original visual design, responsive CSS, embedded profile image, Three.js background, scroll effects, skill ring, experience animation, and interactions are retained.

## Run locally

```bash
npm i
npm run dev
```

Open the local URL printed by Vite.

## Production

```bash
npm run build
npm run preview
```

Three.js is now installed through npm instead of the original CDN script, so the project is self-contained.
